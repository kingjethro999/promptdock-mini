Prompt Dock Mini

A tiny tool that turns a messy, half-formed intention into a precise, editable AI prompt — by showing you its interpretation before it writes the prompt.

The Unique Kernel

The interpretation is the product, not the prompt. Mini pauses in the middle and shows you what it thinks you meant — Goal, Audience, Constraints, Output — as small editable pieces, and lets you correct them before the final prompt exists.

Cut test: delete that middle step and Prompt Dock Mini becomes indistinguishable from every other “paste text → get fancy prompt” generator. That's how we know it's the kernel.

“It's almost a tiny intention compiler. The rough thought is the source language. Mini parses it into meaning. Then it compiles that meaning into a prompt.”

Who It's For

Somebody who already uses AI and keeps getting mediocre results — because there's a gap between what they mean and what they type. Not prompt engineers; they'd never be marketed to. Their shared trait: they think in intentions, not prompts.

The developer

“Build authentication.” “Fix this mobile view.”

The designer

Knows the feeling, hasn't found the words an image model needs.

The student / job seeker

“Help me understand this.” “Make my CV fit this role but don't lie.”

The person writing to someone

“Help me say this without sounding weird.”

Today they hand-type a thin prompt and accept the weak result — or rewrite and retry four or five times until it's good enough.

The Core Loop

  1. Open it

    Near-empty screen: one large input, “What are you trying to get done?”, and underneath — quietly — “Messy is fine.” No welcome tour, no signup.

  2. Dump the thought

    Exactly as they'd message a friend. Messy is the point.

  3. Mini shows its understanding first

    The raw text shifts into compact editable pieces. Each carries provenance: known (you said it) or inferred (tiny sparkle / dotted underline — “Prompt Dock inferred this from your description”). Click any piece to correct it or add one.

  4. Gaps never appear as a state

    “Missing” exists only while Mini reasons. Every gap resolves before you see it: infer it when a reasonable assumption wouldn’t materially change the result, or ask when a wrong guess would. One question at a time, re-evaluated after each answer — hard ceiling of 3. After that, everything unresolved becomes a visible inferred assumption. Never a questionnaire.

  5. Build prompt

    Not a generic “Generate.” The final prompt lands in a real editor — something you own. Read it, edit it directly, copy it.

  6. Recent docks

    Local only, latest 10, newest first — written only after a successful generation. Stores the thought, interpreted fields with provenance, follow-up answers, the prompt, and a timestamp. Reopening restores an editable state rather than forking a copy. Auto-titled from the Goal. One delete button.

The Gap Rule locked

One signal — a hole in the interpretation — with exactly two expressions. “Missing” is never a state the user sees; it only exists while Mini is reasoning.

No questions

“landing page for a bookkeeping app” → professional tone, responsive layout, common SaaS sections. All safe inferences.

Asks

“prepare me for my football trial” with no idea what to actually produce — training plan? nutrition? tactics? That choice changes everything downstream.

The Three States

The interface changes state as the thought becomes concrete. The progression is Think → Shape → Prompt — not a stepper you click, something you feel.

State 01
Raw

Your thought is the dominant object. Huge, unedited, yours.

State 02
Interpretive

The product's understanding takes over. Editable pieces, subtle provenance.

State 03
Finished

The prompt becomes the dominant object — a thing you own and edit.

Inspiration & Identity

Calm writing surface, not an AI product

Reference: Cursor IDE (https://cursor.com) — the tool that made the learner think “I'd love to make something like that.”

Rejected out loud: purple-blue gradients, glowing neural-network imagery, five floating cards, “Supercharge your productivity with AI.”

One primary surface, lots of whitespace, strong typography

The user's thought is dominant at the start; the interpretation takes over next; the finished prompt takes over last.

Speed is a design property

One strong structured generation request returning JSON understanding + prompt draft. No multi-agent architecture — “if Mini takes thirty seconds because it runs six agents, the magic disappears.”

Examples that look imperfect

A few rotating messy thoughts (“Try: I need help planning…”), never a template gallery. The examples themselves should look unfinished — that's the permission slip.

Why This Matters to the Learner

“I would like to properly understand / master prompt engineering in order to get tasks done efficiently without much revisions or hitting back and forth when working.”

Building a tool whose entire job is structuring intent is the most direct route to that. They build with agents all day (Codex, Claude Code, Cursor, Antigravity) and have written AGENTS.md briefs in 47 files because they've felt the cost of a vague instruction firsthand. And they chose “for other people” as the hackathon goal — they want strangers to use it.

The POC Boundary

In, tightly:

  • One screen, three states: thought → interpretation → prompt.
  • One AI call per step: structured generation returning JSON understanding + prompt draft; gated follow-ups that regenerate.
  • Editable interpretation pieces with known / inferred provenance — gaps resolve before display.
  • Follow-up questions: one at a time, max 3 per dock, re-evaluated after each answer.
  • One primary action button: Build prompt.
  • Full-height prompt editor with copy.
  • Recent docks: local storage, last 10, newest first, saved only on success, restores editable, auto-titled from Goal, deletable. No accounts, no sync.
  • Deployed to Vercel.
  • Planning docs in the repo.

Now · Later · Cut

Now proof of concept
  • Thought → interpretation → promptOne screen, three states, no navigation during the core flow.
  • Editable interpretation chipsKnown / inferred provenance, click to correct. Gaps resolve to inferred or a question.
  • Gated follow-upsOne sharp question at a time, only when the answer materially changes the prompt.
  • Build prompt → full editor → copyThe output should feel like an object you own, not a tiny card.
  • Recent docks (local)Last 10, save on success only, restore editable, auto-title from Goal, delete. Continuity without accounts.
  • Vercel deploy + planning docsLive URL for a “for other people” build; scope.md, prd.md, spec.md in the repo.
Later not now
  • Regenerate for a different target“Make this for ChatGPT / a coding agent / an image model / shorter / as a system instruction.” The architecture already supports it — the generated prompt is just one representation of the understanding object.
  • Voice capture of a thought
  • Accounts + cross-device sync
  • Prompt version history / restore / compare
  • Structure-strength controlHow structured the output prompt reads.
  • Run the prompt against a provider
  • Template library, tags, search
  • The full Prompt Dock productSharing, public links, referrals, usage rewards, teams.
Explicitly cut out
  • Accounts, auth, email verification, sessions— history is local only. The demo must open straight into the input; auth is a whole second product.
  • Public sharing / prompt links / referrals / invite rewards— social growth mechanics. Nothing about the kernel needs another person to see it.
  • Provider selection and BYOK settings— one backend AI path. Settings are not the argument; the argument is thought → understanding → prompt.
  • Template galleries and category browsing— replaced by a few imperfect example thoughts. A gallery teaches the user to shop instead of think.
  • Multi-agent / multi-step pipeline— one structured request plus gated follow-ups. Latency kills the magic and the architecture doesn't need it.
  • “Run prompt” / in-app chat with the result— it pulls the demo toward a chatbot, the opposite of the point.
  • Onboarding tour and marketing copy— the app opens on the input. No “Welcome to Prompt Dock Mini, your AI-powered prompt optimization companion.”
  • Library management in Recent docks— renaming, folders, tags, search, pinning. Ten rows with a delete button is the whole feature.
  • A “missing” chip as a visible state— gaps resolve to inferred or question before the user sees them. Three provenance states is a questionnaire with extra steps; two is a product.
